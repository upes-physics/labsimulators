Theory

Constructive interference occurs when the path difference between X-rays reflected from adjacent lattice planes is an integer multiple of the wavelength.

nλ = 2d sinθ
d = λ/(2 sinθ),   n = 1
a = d√(h² + k² + l²)

Peak width. The simulation combines crystallite-size broadening using the Scherrer relation with a strain contribution. These affect peak width, while wavelength and lattice parameter control peak position.

D = Kλ/(β cosθ)
