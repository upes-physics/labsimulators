# BTech Laboratory Physics

Static GitHub Pages website containing interactive browser-based physics laboratory simulations.

## Experiments

1. UV–Visible Band Gap
2. X-Ray Diffraction

## Publish with GitHub Pages

1. Upload the contents of this folder to the root of the repository.
2. Open the repository **Settings** and select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

The site uses only HTML, CSS, and JavaScript. No build process or external package is required.

## Add another experiment

Place its standalone HTML file in the `experiments` directory. Copy one experiment card in `index.html`, then update the experiment number, title, description, feature labels, and relative link.
